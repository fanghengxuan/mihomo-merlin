# mihomo-merlin v2 面板 UI/UX 设计规范

> 版本：2.0.0-draft  
> 状态：Gate 1 待确认  
> 适用：`mihomo-merlin` v1.7.15 基线上的 v2 前端重做  
> 设计基线：FlClash（`chen08209/FlClash`）的 surfaces / color / shape / typography / metrics / motion / navigation_dock / dashboard style  
> 交付对象：前端开发者、视觉验收设计师、主代理  
> 约束：本文是设计规范，不是实现代码；所有页面只能使用现有 API（见 `docs/API.md` 与 `main.go registerRoutes`），不新增后端接口。

---

## 0. 一页速览

1. **结构用明度，不用边框。** 页面、卡片、块、凹槽四级表面靠明度差分层；列表卡片默认无边框、无阴影。
2. **颜色只表状态。** 全站只有一个主色，主色只用于可操作/可选中；成功、警告、错误只落在文字、图标、chip、进度条上。
3. **导航内容优先。** 桌面 7 项侧栏；移动 5 项浮动 dock +「更多」sheet；App Bar 最多 3 个动作，主操作在 bar 上，不用 FAB。
4. **数字先被读到。** 关键数字 34–40px、w700、tabular-nums；标签 11–13px 弱化；延迟只染文字。
5. **设置不再平铺。** 设置页是 FlClash 式分组列表，12 个子页各自承担一组字段；移动端子页是带返回的推入页。

**三个关键决定（假设，已按此执行）：**

- 默认主题 `system`；读取不到系统偏好时回退 `dark`。
- 6 套主色只改变 primary / onPrimary / focus / chart 第一序列，不改变中性表面与状态色。
- 延迟阈值采用 FlClash：`<600ms` 成功色，`>=600ms` 警告色，超时/0 错误色，未测为次级文字；取代旧面板的 200/500 阈值。

## 1. 设计原则

### 1.1 八条原则

| # | 原则 | 一句可执行规则 | FlClash 依据 | 路由器/低端降级 |
|---|---|---|---|---|
| P1 | 明度即结构 | 任何层级差先用 `page/card/block/inset` 四级填充表达；卡片默认无边框、无阴影，只有仪表盘卡片与浮动层可加 e1/e2 阴影。 | `lib/ui/surface.dart` 的 `SurfaceLevel`；`.agents/surfaces.md` 的 Levels。 | 低端移除阴影，保留明度差；不额外加边框补层次。 |
| P2 | 颜色只表状态 | 全站只有一个 accent；success/warning/error 只出现在文字、图标、chip、进度条上，禁止整卡染色；选中用中性底 + primary 标记。 | `.agents/surfaces.md` 的 State；`lib/ui/color.dart` 的 `success/warning/error`。 | 状态色不变；低端不靠动画闪烁表达状态。 |
| P3 | 大圆角同心 | 常规卡片 24、仪表盘 32/34、sheet 顶部 28、alert 34、胶囊 999；内层圆角 = 外层圆角 − 内边距。 | `lib/ui/shape.dart` 的 `AppCorner`；`lib/views/dashboard/style.dart` 的 `DashboardCorner`。 | 用 `border-radius` 近似 superellipse，不用 SVG clip-path 做超椭圆，避免低端重绘。 |
| P4 | 数字优先 | 关键数字 34–40px w700 + `tabular-nums`，标签 11–13px 弱化；数字永远比装饰先被读到。 | `lib/ui/typography.dart` 的 Dynamic Type；`dashboard/style.dart` 的 `DashboardText.figure`。 | 只用系统字体，无 Web Font；tabular-nums 由系统字体原生支持。 |
| P5 | 动效解释层级 | 只做 200–300ms 的进入/退出/展开/选中动效，解释“谁盖住谁”；尊重 `prefers-reduced-motion`，低端直接 0ms。 | `lib/ui/motion.dart`；`navigation_dock.dart` 的弹簧仅用于 dock。 | 默认无 blur/玻璃/复杂弹簧；低端全部静态。 |
| P6 | 内容优先导航 | 桌面 7 项侧栏、移动 5 项 dock + 更多 sheet；App Bar 最多 3 个动作，主操作在 bar 上，禁用 FAB。 | `lib/ui/navigation_dock.dart`；`.agents/surfaces.md` 的 Navigation。 | dock 改为纯填充 + 顶部发丝分隔线，不做镜头/弹性动画。 |
| P7 | 克制密度 | 可点击行最小 56px，代理组头 pinned 并在滚动时上浮；长记录（连接/日志/规则）用整页列表，不套多层卡片；分隔线从文字起点开始。 | `lib/ui/metrics.dart` 的 `listRowMinHeight = 56`；`surfaces.md` 的 RecordListItem。 | 节点按 100/批、连接最多 200 行、日志最多 500 行渲染；长列表分块更新。 |
| P8 | 代码画图 | 空状态、图标、图表、骨架全部用内联 SVG/CSS/canvas 绘制；不引入位图装饰、外部字体、CDN。 | `surfaces.md` 的 Checking A Change / 空态几何；现有 SVG sprite 方案。 | 图表降为 30 点 5s 重绘；骨架静态；不加载任何图片资源。 |

### 1.2 原则之间的优先级

1. P1/P2 是硬约束：不能为了“好看”加边框、整卡染色或第二个强调色。
2. P3/P4 在移动端优先于信息密度：宁可少放一张卡，也不把数字缩到 20px 以下。
3. P5/P7 在低端设备上可降级，但 P1/P2/P8 不降级。
4. 任何新增页面先问“它属于哪一层表面、它的主操作是什么、它的空/加载/错误态是什么”，三者答不上来就不进入开发。

## 2. 设计 Token

### 2.1 主题装载与持久化

| 项 | 规则 |
|---|---|
| HTML 属性 | `<html data-theme="light|dark" data-accent="blue|violet|teal|green|orange|rose" data-mono="1" data-low-end="1">` |
| localStorage | `mm-theme = light|dark|system`，`mm-accent`，`mm-mono = 1|0`，`mm-lowend = auto|on|off` |
| 默认 | `mm-theme` 缺省为 `system`；系统不可读时按 `dark`。`mm-accent` 缺省 `blue`；`mm-mono` 缺省 `0`。 |
| 防闪 | `<head>` 内联脚本在样式表之前读取 localStorage 并写入 `data-theme/data-accent/data-mono`；首帧必须已经是最终主题，不允许先深后浅。 |
| 跟随系统 | `matchMedia('(prefers-color-scheme: dark)')` 变化时，仅当 `mm-theme=system` 更新 `data-theme`；用户显式选 light/dark 后不跟随。 |
| 纯黑 | `mm-mono=1` 只在 `data-theme=dark` 生效；light 下开关禁用并注明“仅深色生效”。 |
| 浏览器地址栏 | `meta[name=theme-color]` 跟随有效主题：light `#EDEEF1`、dark `#0F1013`、纯黑 `#000000`。 |
| 低端标记 | 自动检测 `navigator.hardwareConcurrency <= 4` 或 `navigator.deviceMemory <= 4`；可在「设置 → 外观 → 低端模式」手动覆盖。 |

**严禁**：在用 `color-mix()` 生成任何颜色；所有半透明颜色用 `rgba(var(--*-rgb), a)`，所有表面用预计算 hex token。

### 2.2 四层表面

四层表面按 FlClash 的 tone 规则折算；中性色 chroma ≤ 3，避免主色把整页染黄/染红。表面不随 6 套主色变化。

| 层级 | 用途 | 浅色（tone/hex） | 深色（tone/hex） | 纯黑（tone/hex） |
|---|---|---|---|---|
| `page` | 页面底色、light 模式 sheet、滚动容器 | 94 `#EDEEF1` | 6 `#0F1013` | 0 `#000000` |
| `card` | 卡片、分组列表容器、dark 模式 sheet、light 浮动层 | 98 `#FBFBFC` | 15 `#1A1B1F` | 9 `#121316` |
| `block` | 卡片内的分段轨道、输入框、图标井、tile、dark 浮动层 | 94 `#EDEEF1` | 21 `#24262B` | 15 `#1B1D21` |
| `inset` | 卡片/块内的日志视口、代码、进度轨、badge、骨架 | 90 `#E3E5E9` | 27 `#2E3136` | 21 `#26282D` |
| `chrome` | 桌面侧栏、桌面 App Bar（窗口 chrome） | `inset` `#E3E5E9` | 14 `#15161A` | 5 `#0A0B0D` |
| `sheet` | 底部 sheet 表面 | `page` `#EDEEF1` | `card` `#1A1B1F`（elevated 一层） | `card` `#121316` |
| `float` | dialog、菜单、popover、toast、dock | `card` `#FBFBFC` | `block` `#24262B` | `block` `#1B1D21` |

**嵌套规则：**

- `block` 只能出现在 `card` 内；`inset` 只能出现在 `card` 或 `block` 内。页面级 tile 用 `card`，不要直接用 `block`。
- 一个组件不在调用点选层级：共享卡片/行组件读取当前表面层级，自动升一级。禁止按“是否在 sheet 里”分支选颜色。
- 浅色是“灰纸交替”：页面灰 94、卡片近白 98、卡内块灰 94、块内凹槽 90。**页面禁止用纯白**（`#FFF`），卡片禁止用纯白，避免眩光。
- 深色只向上变亮：6 → 15 → 21 → 27。深色禁止用比页面更暗的“洞”来表达嵌套。
- `inset` 是地板；不存在第五层。需要第五层时说明容器设计错了，应减少一层容器。

### 2.3 中性色、文字与分隔线

| Token | 浅色 | 深色 | 纯黑 | 用法 |
|---|---|---|---|---|
| `--on-surface` | `#17181B` | `#F2F3F5` | `#F2F3F5` | 标题、正文、值、数字 |
| `--on-surface-rgb` | `23,24,27` | `242,243,245` | `242,243,245` | `rgba()` 的基色 |
| `--on-surface-variant` | `#5D636D` | `#B9BDC6` | `#B9BDC6` | 标签、次级行、时间戳、说明 |
| `--outline` | `#787F89` | `#868C96` | `#868C96` | 图标描边、未选开关的 thumb、禁用图形；**永不做文字色** |
| `--outline-variant` | `#C6CAD1` | `#3A3E45` | `#3A3E45` | 图形/轨道/骨架的弱线；**不做卡片边框** |
| `--divider` | `rgba(23,24,27,.14)` | `rgba(242,243,245,.14)` | `rgba(242,243,245,.14)` | 唯一分隔线颜色 |
| `--hover` | `rgba(23,24,27,.06)` | `rgba(242,243,245,.08)` | `rgba(242,243,245,.08)` | 指针悬停 |
| `--pressed` | `rgba(23,24,27,.10)` | `rgba(242,243,245,.12)` | `rgba(242,243,245,.12)` | 按下 |
| `--neutral-selected` | `rgba(23,24,27,.08)` | `rgba(242,243,245,.08)` | `rgba(242,243,245,.08)` | 侧栏/列表选中底 |
| `--scrim` | `rgba(0,0,0,.20)` | `rgba(0,0,0,.32)` | `rgba(0,0,0,.48)` | sheet/dialog 背景 |
| `--scrim-alert` | `rgba(0,0,0,.20)` | `rgba(0,0,0,.48)` | `rgba(0,0,0,.56)` | alert 背景 |

**规则：**

- 文字只有三级：`on-surface`（标题/值/正文）、`on-surface-variant`（标签/说明）、禁用态用 `opacity: .38`。`outline` 不是文字色。
- 分隔线一律 1px（设备像素比下为发丝线），颜色只取 `--divider`；不要用 `outline-variant` 做分隔线。
- 分隔线从文字起点开始：无图标行从 16px 开始；有 40px 图标井的行从 72px 开始；有 36px 头像的行从 64px 开始。
- 卡片、行、dialog 默认没有 1px 边框。允许出现 1px 线的地方只有：桌面 chrome 与内容交界、输入框聚焦环、分隔线、dock 低端降级时的顶边、拖放目标的聚焦环。

### 2.4 六套主色

主色只驱动：primary 填充按钮、segmented 选中、开关打开、焦点环、dock 选中图标/标签、侧栏选中指示条、图表第一序列。**不驱动表面、状态色、卡片标题、普通文字。**

| ID | 名称 | 浅色 primary | `--accent-rgb`（浅） | 浅色 on-primary | 深色 primary | `--accent-rgb`（深） | 深色 on-primary |
|---|---|---|---|---|---|---|---|
| `blue` | 海湾蓝（默认） | `#007AFF` | `0,122,255` | `#FFFFFF` | `#58A6FF` | `88,166,255` | `#001A33` |
| `violet` | 暮光紫 | `#6D4AFF` | `109,74,255` | `#FFFFFF` | `#B7A6FF` | `183,166,255` | `#1B1040` |
| `teal` | 青瓷 | `#00796B` | `0,121,107` | `#FFFFFF` | `#4FD8C8` | `79,216,200` | `#00201B` |
| `green` | 苔绿 | `#2E7D32` | `46,125,50` | `#FFFFFF` | `#7BD88A` | `123,216,138` | `#06210C` |
| `orange` | 琥珀 | `#B45309` | `180,83,9` | `#FFFFFF` | `#FFAA5C` | `255,170,92` | `#2A1200` |
| `rose` | 玫瑰 | `#C2185B` | `194,24,91` | `#FFFFFF` | `#FF8FB1` | `255,143,177` | `#330A18` |

**派生规则：**

- 浅色 primary 的 tone 控制在 35–60，保证白字约 3:1；深色 primary 的 tone 控制在 50–75，高于 60 时用深色 on-primary。
- `--accent-weak` 不单独定义 token，直接用 `rgba(var(--accent-rgb), .10)`；`--accent-line` 用 `rgba(var(--accent-rgb), .35)`。
- 纯黑主题沿用深色主色值。
- 图表第二序列 = 第一序列主色 45% 叠在卡片上，直接用 `rgba(var(--accent-rgb), .45)`；禁止引入 tertiary 作为第二序列。

### 2.5 状态色

状态色固定，不随主色变化。只用于文字、图标、chip、进度条、图表状态点；**不整卡染色**。

| Token | 浅色 | 深色/纯黑 | 背景容器（浅） | 背景容器（深/纯黑） | 用途 |
|---|---|---|---|---|---|
| `--ok` | `#1B7F4B` | `#6FDC9A` | `#DFF3E7` | `#123A27` | 运行中、正常、成功、延迟 <600ms |
| `--warn` | `#A85B00` | `#FFC46B` | `#F7E9D2` | `#3A2A10` | 受限、需注意、延迟 ≥600ms、未应用 |
| `--err` | `#BA1A1A` | `#FFB4AB` | `#F9DEDC` | `#3B1A19` | 失败、超时、删除确认中的警示 |
| `--destructive` | `#FF383C` | `#FF4245` | — | — | alert 中的破坏性动作文字/图标（iOS systemRed） |
| `--ok-rgb` | `27,127,75` | `111,220,154` | — | — | `rgba()` 基色 |
| `--warn-rgb` | `168,91,0` | `255,196,107` | — | — | `rgba()` 基色 |
| `--err-rgb` | `186,26,26` | `255,180,171` | — | — | `rgba()` 基色 |

**状态映射：**

- 引擎：`running` → ok；`stopped` → 中性（不是错误）；`recovering/autoRecover` → warn；`start failed` → err。
- iptables：`applied` → ok；`not applied` 且引擎运行 → warn；引擎停止时 → 中性。
- 订阅：`ok` → ok；`error` → err；`never` → 中性。
- 连通性：`ok` → ok；`restricted` → warn；`timeout` → 中性文字（不是 err，因为可能是目标站点慢）；`fail` → err；`unknown` → 中性。
- 延迟：`null/未测` → `on-surface-variant`；`1–599ms` → ok；`>=600ms` → warn；`0/超时` → err。
- 存储：`>85%` 用量 → warn；清理失败 → err；其余中性。

### 2.6 圆角

| Token | 值 | 用途 |
|---|---|---|
| `--r-xs` | 4px | badge 内的极小块、进度条端头 |
| `--r-sm` | 8px | 卡内小 tile、内联代码块 |
| `--r-md` | 16px | 输入框、icon 井、tile、node avatar、table header |
| `--r-lg` | 20px | 卡内 block、group 头部、popover 内块 |
| `--r-xl` | 24px | 常规卡片、订阅卡、设置分组、记录卡 |
| `--r-xxl` | 28px | sheet 顶部、宽 dialog、dropzone |
| `--r-dash` | 32px（≥600）、34px（<600） | 概览仪表盘卡片 |
| `--r-alert` | 34px | confirm / login / alert |
| `--r-pill` | 999px | 按钮、chip、segmented、搜索框、dock |

**同心圆角公式：** `inner-radius = outer-radius − padding`，且不小于 8px。

| 外层 | 内边距 | 内层 |
|---|---|---|
| 仪表盘 32 | 20 | 12 |
| 仪表盘 34（手机） | 20 | 14 |
| 常规卡片 24 | 16 | 8 |
| 卡片 24 | 12 | 12 |
| sheet 28 | 16 | 12 |
| alert 34 | 20 | 14 |

不要用 `clip-path` 画超椭圆；`border-radius` 在低端设备上是单次绘制，超椭圆 path 会增加光栅化成本。

字体栈（只用系统字体，禁止 Web Font）：

**数字规则：**

- 所有数字加 `font-variant-numeric: tabular-nums`；关键数字再加 `letter-spacing: -0.02em`。
- 关键数字只用 `display` / `largeTitle` / `title1`；不要在 14px 的正文里塞大数字。
- 标签/单位用 `footnote` 或 `caption1`，颜色 `on-surface-variant`，不要用 `outline`。
- 中文不额外加 letter-spacing；数字/英文才用负字距。
- 不允许用全大写英文做标签（中文界面无此习惯）；专有名词保持原样（DNS、QUIC、HTTP）。

### 2.9 阴影

只有两类阴影：仪表盘卡片 e1；浮动层（dock、sheet、dialog、toast、popover）e2。列表卡片、设置分组、订阅卡、规则/连接列表**没有阴影**。

| Token | 浅色 | 深色 / 纯黑 |
|---|---|---|
| `--shadow-e1` | `0 .5px 1px rgba(0,0,0,.05), 0 2px 6px rgba(0,0,0,.04), 0 12px 32px -6px rgba(0,0,0,.09)` | `0 1px 2px rgba(0,0,0,.50), 0 10px 28px -6px rgba(0,0,0,.55)` |
| `--shadow-e2` | `0 1px 3px rgba(0,0,0,.06), 0 10px 24px rgba(0,0,0,.08), 0 32px 64px -12px rgba(0,0,0,.22)` | `0 2px 6px rgba(0,0,0,.50), 0 32px 64px -12px rgba(0,0,0,.70)` |
| `--shadow-none` | `none` | `none` |

**规则：**

- 深色阴影几乎不可见，浮动层靠“比卡片亮一级”+ 阴影共同成立；纯黑下尤其如此。
- 低端设备 `--shadow-e1/e2: none`；浮动层改用 `sheet/float` 填充 + `--divider` 顶边/边缘线。
- 不要用 `filter: drop-shadow()` 给每个列表项加阴影；这是低端设备最大的光栅开销之一。

### 2.10 动效

| Token | 值 | 用途 |
|---|---|---|
| `--dur-fast` | 200ms | hover、按下、开关、chip 选中 |
| `--dur-mid` | 250ms | 页面内容淡入、dialog 进入、toast |
| `--dur-slow` | 300ms | sheet 进入/退出、设置子页推入 |
| `--ease-standard` | `cubic-bezier(.2,0,0,1)` | 大多数属性 |
| `--ease-out` | `cubic-bezier(.16,1,.3,1)` | 进入、展开 |
| `--ease-in` | `cubic-bezier(.4,0,1,1)` | 退出、收起 |
| `--motion-off` | `0ms` | 低端/reduced-motion |

**规则：**

- 页面切换：内容区 200ms 淡入 + 4px 上移（只对后续切换；首屏不做 opacity 0 动画，避免后台标签页首帧永久半透明）。
- sheet：280ms 从底部上移 24px + 淡入；dialog：250ms 从 `scale(.96)` + 淡入；toast：200ms 从下方 8px。
- 不使用复杂弹簧；dock 不做 FlClash 的镜头/果冻/弹性拖拽，避免低端掉帧。选中态用 200ms 背景/颜色过渡。
- `prefers-reduced-motion: reduce` 或 `data-low-end=1` 时，所有 transform 动画改为 0ms；只保留颜色/背景的 200ms 过渡（也可全部 0ms）。
- 禁止对 `height`、`width`、`top/left` 做布局动画；用 transform/opacity。

## 3. 信息架构

### 3.1 导航

#### 桌面（≥1024）

- 窄侧栏，宽 96px，chrome 表面；顶部品牌标记（平面单色，不用渐变），中部 7 项导航，底部引擎状态 + 版本。
- 7 项固定顺序：**概览 / 节点 / 订阅 / 规则 / 连接 / 日志 / 设置**。
- 选中态：8% 中性填充（`--neutral-selected`）+ 左侧 3×16px primary 指示条；图标/文字保持 `on-surface`，**不整行染 primary**。
- 悬停：`--hover` 8% 中性填充；不做位移/放大。
- 侧栏与内容交界处允许 1px `--divider`；这是窗口 chrome 的边，不是卡片边框。
- 底部状态：小圆点 +「运行中/未运行」+ `v2.0.0`；点击回概览。停止状态用中性色，不用红色。

#### 移动（<1024）

- 5 项浮动 dock：**概览 / 节点 / 订阅 / 连接 / 设置**。
- dock 高 62，左右边距 21，底部边距 `max(21px, env(safe-area-inset-bottom))`；胶囊 999，浮在内容上，不占文档流。
- 选中项：图标 + 10/14.5 标签用 primary；背后是比 dock 高一级的中性“platter”（浅色 `card`、深色 `block`），不是 primary 填充。
- 未选中：`on-surface-variant`；hover 仅指针设备。
- **更多**：dock 根页面（概览/节点/订阅/连接/设置）右侧 App Bar 的「⋯」打开「更多」sheet；规则/日志/外观/诊断收在 sheet 里。
- 规则、日志、设置子页、外观、诊断是**推入页**：App Bar 左侧返回，dock 隐藏，返回恢复上一个 dock 根页面；无历史时回概览。
- 移动端不做 7 项底部 Tab，不做横向滚动的 Tab，不做 FAB。

#### 保存模型

- **表单子页**（代理、DNS、订阅拉取、国内 IP 规则、自动选择、定时重启、启动与访问）：进入时从 store 复制一份基线；字段改动只改草稿，App Bar「保存」由脏状态点亮。保存时只 PUT 本页涉及的字段；成功后更新 store 并清脏；失败保留草稿，页面顶部错误条 + toast，不关闭页面。
- **即时项**：外观（localStorage）、日志页的日志级别（PUT 立即生效）、概览的模式分段（PUT 立即生效）。即时项不进入草稿。
- **动作子页**（内核、备份、存储、诊断）：没有保存按钮；每个动作独立请求，按钮有 loading。
- 离开有脏草稿的子页时，弹确认「放弃未保存的更改？」；确认后丢弃草稿。
- 单 store：概览修改模式后，设置/代理页再次进入时必须显示最新模式（修复旧面板 H1/H2 的状态不同步）。
- 订阅编辑不得把打码 URL 回写（修复 H3）；编辑时用 `GET /api/subs/{id}?reveal=1` 取原文，保存时提交原文。

## 6. 响应式与布局

### 6.1 断点

| 断点 | 范围 | 导航 | 布局 |
|---|---|---|---|
| Desktop | ≥1024 | 96px 侧栏 7 项 | 4 列仪表盘；设置双栏；App Bar 72 |
| Compact | 600–1023 | 浮动 dock 5 项 + 更多 | 2 列仪表盘；设置单列列表→推入；App Bar 64；内容边距 24 |
| Mobile | <600 | 浮动 dock 5 项 + 更多 | 1 列；设置列表→推入；App Bar 56；内容边距 16；dialog 可转 sheet |

- 断点用 `min-width`/`max-width` 媒体查询；不要用 JS 监听窗口宽度做布局类切换（除路由/dock 隐藏）。
- 1024 是侧栏/dock 的分界；600 是双列/单列与 32/34 仪表盘圆角的分界。
- 320px 宽度也必须无横向滚动；390×844 是主要验收手机尺寸。
- 安全区：dock、sheet 底部、页面底部使用 `env(safe-area-inset-bottom)`；刘海屏顶部用 `env(safe-area-inset-top)`。
- 软键盘：输入框滚动到可视区；`scroll-padding-bottom` 考虑 dock；设置子页保存按钮不被键盘遮。

### 6.2 移动端规则

- 推入页：从右滑入 24px + 淡入 200ms；返回反向；低端即时。dock 隐藏。
- 设置子页保存按钮在 App Bar 右侧；表单字段单列；按钮全宽或右对齐。
- 连接表、规则表必须变卡片/分行，不允许横向滚动。
- 日志/原始内容/进度占满可用高度；toolbar sticky。
- 更多 sheet 最大 60dvh；不应覆盖 dock 的触控区域（sheet 关闭后才能点 dock）。
- 触摸目标 ≥44×44；节点测速、连接关闭、复制按钮不能只在 hover 出现。

### 6.3 键盘与无障碍

- 所有交互控件可 Tab 到达；顺序与视觉一致；正文字体不小于 13px。
- `:focus-visible` 显示 2px accent 环 + 2px 间隔；实心 primary 按钮用外扩环（1px page + 3px accent）避免环被填充吞掉。
- 原生 `<dialog>.showModal()` 提供焦点圈禁；Esc 关闭；关闭后焦点返回触发元素。
- `aria-live="polite"` 用于 toast 和状态 chip；日志视口用 `aria-live="off"`（避免刷屏），提供暂停。
- 状态不能只靠颜色：延迟有 “ms/未测/超时”，chip 有文字，开关有 `aria-checked`，连通性有文字状态。
- 不禁止用户选择日志/URL 文本；`pre` 与 URL 允许复制。
- 尊重 `prefers-reduced-motion`；不要因动画阻塞首屏。

## 7. 低端设备降级（`data-low-end="1"`）

**检测：**

```
mm-lowend = localStorage('mm-lowend') || 'auto'
lowEnd = mm-lowend === 'on'
      || (mm-lowend === 'auto' && (
           navigator.hardwareConcurrency <= 4 ||
           navigator.deviceMemory <= 4 ||
           matchMedia('(prefers-reduced-motion: reduce)').matches
         ))
```

同时，任何 `prefers-reduced-motion: reduce` 都至少关闭 transform/opacity 动画，即使未开启低端模式。

| 项目 | 正常 | 低端 |
|---|---|---|
| 阴影 | e1/e2 | `none`；浮动层用 fill + 1px divider |
| blur/backdrop-filter | 本版本默认不用 | 禁用（CSS 中不得出现） |
| 动效 | 120/200/300ms | 0ms；只保留必要的颜色变化 |
| 骨架 | 1.4s opacity 脉冲 | 静态块，不脉冲 |
| 图表 | 60 点，2s 重绘，面积渐变 | 30 点，5s 重绘，只画折线不填充 |
| 节点列表 | 100/批 | 50/批 |
| 连接 | 200 行 | 100 行 |
| 日志 | 500 行 | 300 行 |
| 轮询 | status 10s、connections 2s | status 15s、connections 5s；隐藏页 0 |
| 测速/测试态 | spinner + 文字 | 静态文字「测试…」，不闪 |
| 卡片 hover | 填充变化 | 无 hover（触摸） |
| 滚动 | `scroll-behavior:smooth`（可选） | `auto` |
| dock | 填充 + 阴影 | 填充 + 顶边 divider，无阴影 |
| CSS 滤镜 | 不用 `filter` 做 hover | 禁用 |

**路由器侧：**

- `web/` 原始体积 ≤300KB（JS ≤150KB、CSS ≤60KB），gzip 后更小；无图片、无字体、无 CDN。
- 静态资源带版本戳（`plugin/version`），升级后不会读到旧缓存。
- 低端渲染不改变 API 轮询契约；仅在页面可见时请求。

## 9. 禁止出现的旧模式

以下模式在 v2 中一律禁止；静态检查应能拦住可机器判定的项。

1. **1px 边框卡片**：`.card { border: 1px solid ... }`、用 `outline-variant` 给卡片描边；卡片靠明度分层。
2. **整卡状态色**：错误订阅整卡红、成功整卡绿、引擎停止整卡灰红；状态只上文字/图标/chip。
3. **整行/整卡 primary 选中**：`background: var(--primary)` 或 `primaryContainer` 用于选中行/卡片；选中用中性底 + primary 标记。
4. **window.confirm / alert / prompt**：全部替换为 `MM.ui.confirm` / alert dialog。
5. **`color-mix()`**：全部改 `rgba(var(--*-rgb), a)` 或预计算 token。
6. **FAB**：任何页面不得出现浮动操作按钮；主操作在 App Bar 或页面按钮。
7. **12 张卡片平铺设置**：设置必须是分组列表 + 12 子页；禁止把全部设置字段堆在一个长页。
8. **6+ dock 项 / 7 项移动 Tab**：移动 dock 固定 5 项；规则/日志/外观/诊断进更多 sheet。
9. **多层卡片套卡片**：超过两层容器（page→card→block 之后不再 card）视为结构错误；用 block/inset。
10. **outline 做文字色**：灰色文字必须是 `on-surface-variant` 或禁用 opacity；`outline` 只做图形。
11. **装饰性渐变/径向光晕/品牌渐变 logo**：背景只用表面填充；图表面积渐变除外，低端关闭。
12. **位图装饰（favicon 除外） / 外部图片 / Web Font / CDN**：图标用内联 SVG；空状态用代码几何；字体用系统栈。
13. **默认 blur / backdrop-filter / 玻璃**：本版本不做 glass；低端更不得出现。
14. **首屏 opacity:0 入场导致半透明**：首屏不做 opacity 0 动画；后台标签页不能留下半透明页面。
15. **移动端横向滚动表格**：连接/规则/设置必须卡片化或分行。
16. **hover-only 操作**：测速、关闭连接、复制等必须在触摸设备可见/可点。
17. **首屏无限 spinner / 骨架闪烁**：400ms 内不闪骨架；有缓存保留旧数据。
18. **日志自动滚动抢用户滚动**：只有用户在底部才自动滚；上滚后提供「回到最新」。
19. **整块红色 toast / 整块红色错误卡**：错误用文字/图标 + 容器色，不用大面积红底。
20. **未标注的图标按钮**：所有图标按钮必须有 `aria-label`/`title`；触控区 ≥44。
21. **用 `filter: brightness()` / `drop-shadow()` 做 hover 或列表阴影**：交互用背景填充，阴影只用两个阴影 token；`drop-shadow` 禁止用于列表项。

### 10.2 实现边界（给前端开发者）

- 不引入框架、npm、构建步骤、CDN、Web Font、位图；经典脚本，`window.MM` 命名空间，`defer` 顺序加载。
- 不新增后端接口、不改 API 字段；`connections` 用 `?legacy=0` 减半 payload。
- 使用原生 `<dialog>.showModal()`；开关用可聚焦原生 checkbox；键盘/Esc/焦点圈禁必须可用。
- 路由用 hash；旧 hash 兼容；页面挂载一次，轮询只更新文本/class；列表 keyed diff。
- 首屏并行 `Promise.allSettled` 加载 settings/status/subs/intranet/netinfo/reachability；设置相关数据在路由挂载时加载；400ms 后显示骨架；失败保留旧数据 + 重试。
- 主题防闪脚本在 `<head>` 内联；`mm-theme/mm-accent/mm-mono/mm-lowend` 持久化。
- 静态检查（更新后的 `tests/ui_check.py`）应扫描 `web/**`，检查：标签平衡、id 引用、`node --check`、脚本顺序/版本戳、禁止 `window.confirm`/`color-mix`/`backdrop-filter`/外部 URL、关键类名、路由注册。
- 视觉验收按第 8 节截图矩阵执行；同一根因修复最多 2 次，第 3 次停下汇报。

### 10.3 已知取舍

1. **默认 system 而非 dark**：尊重系统偏好；读取不到时回退 dark。
2. **表面不随主色变化**：换取 6 套主色稳定、token 可预计算；FlClash 的 tinted 模式不采用。
3. **延迟阈值改为 <600/≥600**：与 FlClash 一致；旧面板的 200/500 废弃。
4. **移动端规则/日志是推入页**：因为 dock 固定 5 项；桌面仍是侧栏根页面。
5. **设置页级保存**：避免旧面板“部分自动保存、部分手动保存”的不一致；外观/日志级别例外，即时生效。
6. **不做 glass/模糊**：本版本性能优先；如果未来启用，必须作为可选且默认关闭，并提供低端禁用。
7. **体积超出 V-38，接受偏差**（2026-10-31 决策）：JS 原始 246KB（gzip 58KB）、CSS 55KB、`web/` 约 332KB，超过 150KB / 60KB / 300KB 的目标。原因是不引入构建步骤与源码/压缩产物分离，保持 `web/**` 直接可读可改；路由器内网经 gzip 后仅约 58KB，实际加载开销可接受。V-38 的体积项按此例外记录，其余静态检查项仍为硬性要求。
